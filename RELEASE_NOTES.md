# Alice Homebrew 0.5.4

Исправлена потеря журнала при остановке нативного плагина: вместо одного `exit status 1` теперь остаются последние диагностические строки.

- Последние 32 строки (до 2048 байт каждая) сохраняются локально после ошибки, выключения плагина и перезапуска менеджера. Удаление плагина удаляет и его журнал. Логи никуда не отправляются.
- Журнал на странице плагина обновляется при опросе статуса, даже если процесс уже завершился. Ошибка и кнопка включения тоже обновляются; форма конфигурации не перерисовывается.
- Сохраняется последняя строка вывода без завершающего перевода строки.
- Панель Alice Legacy Fix объясняет автоматическое скачивание комплекта вместо показа музыкального проигрывателя. Для автозагрузки обновите сам плагин до 0.1.0-beta.2 через магазин.

Обновление: Настройки → Обновления менеджера → Проверить сейчас. Плагины и их настройки сохраняются. Автоматическая проверка стабильных релизов раз в 5 часов продолжает работать. Прямой установки обновления на физическую колонку при подготовке выпуска не выполнялось.
