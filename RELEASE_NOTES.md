# Alice Homebrew 0.2.0

Менеджер работает на самой Мини 1 и открывается по IP без входа и токена.

- Наш официальный подписанный источник включён по умолчанию; можно добавлять сторонние каталоги после проверки подписи и подтверждения доверия.
- В настройках показаны диск, оперативная память, память Homebrew и размеры пакетов/точек отката. При нехватке места предлагается выбрать самые большие плагины для удаления, затем повторить установку.
- Точный ввод чисел и HEX рядом с визуальными настройками, постоянное сохранение и скачивание конфига.
- Установка из каталога, своего файла и по URL/LAN. Отзывы и ревизии разделены между источниками.
- Полные гайды по созданию .aliceplugin и собственного источника на GitHub.
- Windows AMD64, Linux AMD64 и ARM64; RU/EN; пример Ring Studio.

Нужен уже работающий ADB root. Средства получения root, прошивки, личные ключи и индивидуальные изменения колонки в публикацию не входят. Установщик сохраняет штатную Алису и другие приложения.
