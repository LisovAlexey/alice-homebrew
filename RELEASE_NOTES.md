# Alice Homebrew 0.4.0

Менеджер на колонке сам проверяет стабильные релизы нашего GitHub раз в 5 часов и устанавливает более новую версию. Расписание сохраняется после перезапуска. Первая проверка новой установки — примерно через 15 секунд.

- Настройки RU/EN: статус обновления, найденная версия, время проверок, «Проверить сейчас», переключатель автоустановки.
- Проверка источника, версии, архитектуры, размера, SHA-256 и команды version перед остановкой службы.
- Сохранение предыдущего менеджера и конфигурации, корректный перезапуск и проверка готовности новой версии.
- Автоматический откат при отказе запуска и восстановление прерванной замены при старте колонки.
- Сохранение установленных плагинов, их настроек и состояния включения. Прошивка/ADB root/штатная Алиса этим механизмом не меняются.
- Отдельные бинарные assets и выпуск релизов из Version в исходниках: следующему обновлению достаточно нового номера версии.

Homebrew устанавливается на колонке с готовым ADB root. Средства получения root и прошивки в этот публичный релиз не входят. AirPlay остаётся отдельным beta-плагином, не устанавливается обновлением менеджера и не обновляется автоматически.
