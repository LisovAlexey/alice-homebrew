# Alice Homebrew 0.3.0

Нативные плагины SDK 2 для Linux ARM64: микрофон/звук ALSA, датчик, кнопки, подсветка I²C, GPIO, UART, сеть и остальные интерфейсы Linux. Перед включением требуется подтверждение полного root-доступа; нативные плагины не изолированы. WASM SDK 1 сохраняет прежнюю песочницу.

- Проверка статического ELF и SHA-256 без выполнения при загрузке/модерации.
- Запуск/остановка сервисов, ограниченный журнал, перезапуск после сохранения конфига.
- Инвентаризация оборудования в настройках и SDK с примерами input/I²C/ALSA.
- Подписанный каталог v2 для новых клиентов; v1 сохраняет совместимость старых.
- AirPlay 1.0.0-beta.1: экспериментальный аудиоприёмник на Shairport Sync 5.6.1. iPhone и колонка должны быть в одной локальной сети. Без зеркалирования экрана и без заявления поддержки AirPlay 2/multiroom. Поток с реального iPhone ещё не проверен: пакет оставлен для ручной установки владельцем.

В релиз входят только Homebrew и плагины. Прошивок, средств получения root, ключей ADB и приватных данных нет.
