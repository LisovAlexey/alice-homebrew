# AirPlay для Alice Homebrew

Экспериментальный **аудиоприёмник AirPlay** для Яндекс Станции Мини первого поколения, YNDX-0004, Linux ARM64. Нужен Homebrew 0.3.0 или новее и готовый ADB root. Версия `1.0.0-beta.1`.

После установки из официального каталога откройте конфиг, задайте имя, при необходимости пароль и ограничение громкости, сохраните и включите плагин. iPhone/iPad/Mac и колонка должны находиться в одной локальной сети без изоляции клиентов Wi-Fi. В Пункте управления iPhone откройте список устройств вывода звука AirPlay и выберите `Alice Mini` (или заданное имя).

Выход по умолчанию — PCM 0 TDM-B. Если звука нет, попробуйте PCM 1 TDM-C и проверьте, не занят ли ALSA другим сервисом. Сохранение конфига перезапускает включённый плагин. По умолчанию максимум ограничен −10 дБ; начните с небольшой громкости на телефоне.

Это AirPlay classic/RAOP для звука, без зеркалирования экрана, без заявления совместимости AirPlay 2, multiroom и DRM-сервисов. Реальный поток с iPhone на колонку ещё **не проверен**; пакет подготовлен для ручного тестирования владельцем. Установщик Homebrew не устанавливает этот плагин автоматически.

## Доступ и зависимости

Нативный сервис работает с root без песочницы. Назначение: аудиовыход, TCP/UDP и mDNS в локальной сети. Микрофон, камера, датчик и облачные сервисы ему не нужны, запись звука не выполняется. Перед включением менеджер запрашивает явное подтверждение полного системного доступа.

Пакет самодостаточен: статические ARM64 Shairport Sync и Go-сервис обнаружения встроены в `plugin.elf`. Системные ALSA-конфиги не переписываются. Рабочие файлы остаются в каталоге данных плагина. Используются TCP-порт из настроек (7000 по умолчанию), UDP RTP/контроль/синхронизация Shairport и UDP 5353 mDNS. Доступ из интернета для приёма музыки не требуется.

Основные компоненты: Shairport Sync 5.6.1, FFmpeg 8.1.3 (ALAC/PCM, без программ/сетевых демультиплексоров), ALSA 1.2.16.1, OpenSSL 3.5.6, libconfig 1.8.3, popt 1.19, HashiCorp mDNS 1.0.7. Устаревшие декодеры Hammerton/Apple ALAC и tinysvcmdns не включены. При изменении зависимостей проверяйте актуальные исправления upstream.

## Проверка и исходники

Проверки версии, RTSP/Apple-Challenge и формирования RAOP TXT выполняются под QEMU на ПК; они не заменяют тест реальной передачи и динамика. Источники менеджера и плагина открыты. Отдельный архив `AirPlay-1.0.0-beta.1-source.tar.gz` в релизе содержит точные исходные архивы зависимостей, изменения и инструкции сборки/перелинковки. Нельзя заменять его только ссылками на upstream при распространении готового пакета.

Сборка приёмника: `bash plugins/airplay/build-receiver.sh`. Нужны Linux, ARM64 cross GCC/G++, make, pkg-config, autoconf, automake, libtool, perl, flex/bison и curl. Затем `python3 plugins/airplay/build-plugin.py` из корня репозитория (Go 1.26.5 в PATH). Сборка не устанавливает и не включает плагин на колонке.
